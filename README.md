# 공유보드

수업에서 만든 발표자료(웹 슬라이드)의 주소를 올리면, 한 화면에 모이는 보드입니다.
카드의 미리보기 안에서 바로 넘겨 볼 수 있고, ‘사이트 바로 가기’를 누르면 그 사람의 사이트로 갑니다. 같은 사이트에서 Gmail 실습에 쓸 메일도 받을 수 있습니다.

HTML 파일 몇 개로 된 사이트라서 따로 빌드하지 않습니다. GitHub Pages에 올리면 바로 열립니다.

## 어떻게 만들어졌나

| 역할 | 무엇으로 | 하는 일 |
|---|---|---|
| 화면(프런트엔드) | HTML · CSS · JavaScript, GitHub Pages | 보드를 보여 주고, 입력을 받습니다 |
| 저장(데이터베이스) | Firebase Firestore + 익명 로그인 | 올린 이름·제목·주소·코드를 저장하고, 열어 둔 모든 화면에 바로 보여 줍니다 |
| 메일(백엔드) | Google Apps Script 웹 앱 | 화면이 부탁하면 정해진 실습 메일 한 통을 보냅니다 |

## 파일

```
index.html        보드 화면 (실습 메일 받기 · 내 결과물 올리기(접혀 있다가 ‘올리기 열기’로 펼침) · 공유된 결과물)
mail-preview.html 어떤 실습 메일이 오는지 보여 주는 미리보기 — ‘어떤 메일이 오나요?’ 링크가 여기로 갑니다
view.html         붙여 넣은 코드를 화면 가득 보는 화면(주소 끝에 ?id=문서ID. 보드에는 버튼을 두지 않았습니다)
admin.html        담당자용 대시보드 — 제출한 사람 목록(학번 포함)과 결과물 전체 내려받기
admin.js          대시보드의 동작
zip.js            여러 파일을 ZIP 하나로 묶는 작은 도구
guide.html        실습 안내서 사본 — 머리글의 ‘실습 안내서’ 링크가 여기로 갑니다
style.css         모양
app.js            보드 화면의 동작
store.js          데이터를 읽고 쓰는 부분 (Firebase 또는 데모 모드)
samples.js        데모 모드에서만 보이는 예시 카드
config.js         설정 — 이 파일만 고치면 됩니다
firestore.rules   Firestore 보안 규칙 (Firebase 콘솔에 붙여 넣는 내용)
apps-script/
  Code.gs                  실습 메일을 보내는 Apps Script 코드
  실습 메일_미리보기.html     보내는 메일의 모습
설정 방법.md       Firebase · Apps Script · GitHub Pages 를 연결하는 순서
```

## 바로 열어 보기 (데모 모드)

`index.html`을 더블클릭하면 열립니다. `config.js`의 Firebase 값이 비어 있으면 **데모 모드**로 동작합니다.

- 예시 카드 9개가 올라와 있습니다(이름과 프로젝트는 지어낸 것입니다).
- 올린 내용은 그 브라우저에만 저장됩니다. 다른 사람에게는 보이지 않습니다.
- 메일 받기 버튼은 꺼져 있습니다.

실제 수업에서 쓰려면 `설정 방법.md`의 순서대로 연결합니다.

## 미리보기가 보이는 방식

카드의 미리보기는 세 가지 중 하나로 보입니다.

1. **HTML 코드를 함께 붙여 넣은 경우** — 그 코드를 작은 화면으로 그려 첫 장을 보여 줍니다.
2. **다른 사이트 안에 넣을 수 있는 주소인 경우**(GitHub Pages, Firebase Hosting, Netlify, Vercel, Cloudflare Pages) — 그 주소를 그대로 작은 화면으로 보여 줍니다.
3. **그 밖의 주소** — 제목과 이름으로 만든 포스터를 보여 줍니다.

Google Sites로 게시한 페이지와 Gemini 공유 링크는 다른 사이트 안에 넣는 것을 스스로 막아 두었습니다(`X-Frame-Options: DENY`). 그래서 주소만 올리면 3번 포스터로 보이고, 코드를 함께 붙여 넣으면 1번처럼 첫 장이 보입니다.

## 안전을 위해 해 둔 것

- 사람이 적은 글자(이름, 제목, 소개)는 글자 그대로만 화면에 넣습니다. HTML로 해석하지 않습니다.
- 붙여 넣은 HTML 코드는 `sandbox`를 건 iframe 안에서만 그립니다. 그 코드는 이 사이트의 저장소나 다른 카드에 닿지 못합니다.
- 주소는 `https://`로 시작하는 것만 받습니다.
- 누구나 볼 수 있지만, 고치기와 지우기는 올린 브라우저에서만 됩니다(익명 로그인으로 구분).
- 학번은 보드에 보이지 않게 따로 저장합니다. 올린 사람과, 대시보드에서 관리 코드를 맞게 넣은 사람만 읽을 수 있습니다. 관리 코드는 Firebase 콘솔에서만 정하고, 화면에서는 읽을 수 없습니다.
- 올리기와 고치기는 강사가 올리기를 열어 둔 동안에만 됩니다.
- `config.js`의 Firebase 값은 공개되어도 되는 값입니다. 무엇을 쓸 수 있는지는 `firestore.rules`가 정합니다.
- 실습 메일은 내용이 정해진 한 통만 보내고, 하루 보낼 수 있는 수와 같은 주소로 다시 보내는 간격에 제한이 있습니다.

## 알아 둘 점

- 미리보기 안에서는 YouTube나 Drive 영상이 재생되지 않을 수 있습니다. 영상은 ‘사이트 바로 가기’로 원래 주소에서 봅니다.
- 코드는 900 KB까지 올릴 수 있습니다. 사진이나 영상을 코드 안에 직접 넣었다면 Drive 주소로 바꿉니다.
- 글꼴(Pretendard, Hahmlet)과 Firebase SDK는 인터넷에서 불러옵니다.
