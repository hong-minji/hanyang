Google 세팅 — 연결 · 맥락 폴더 · YouTube 채널

Gemini에 내 Google을 연결하고, 실습 자료 폴더를 내 드라이브에 연결하고 내 폴더를 만들고, YouTube 채널을 만들어 둔다.

순서

  1. Gemini 왼쪽 메뉴 → 맞춤설정 → Google Workspace 옆 ＋ → 연결
  2. 실습 자료 폴더를 연다 → 폴더 이름 옆 ▾ → 정리 → 바로가기 추가 → 내 드라이브 — 내려받지 않는다
  3. 내 드라이브에 새 폴더 ‘발표_내이름’을 만들고, 그 안에 ‘에셋’ 폴더를 하나 더 만든다 — 실습 자료를 참고해 꾸리는 내 폴더. 오늘 만드는 구성안 · 에셋 · 발표 파일을 여기에 둔다
  4. Gemini 새 채팅 → ＋ → Drive에서 파일 추가 → 실습자료(내 드라이브의 바로가기 또는 공유 문서함) → README.md → 요청문을 보낸다
  5. youtube.com → 오른쪽 위 프로필 사진 → 채널 만들기 → 이름과 핸들 입력

요청문

README 읽혀 보기
첨부한 README를 읽고 이 프로젝트를 세 줄로 요약해 줘.

확인

  • 내 드라이브에 ‘실습자료’ 바로가기와 ‘발표_내이름’ 폴더(안에 ‘에셋’)가 있는가
  • README의 세 줄 요약이 나오는가
  • YouTube 채널이 생겼는가
막히면 — 학교 계정에서 연결 메뉴나 YouTube가 막혀 있으면 개인 계정으로 바꿔서 합니다. ‘Drive에서 파일 추가’ 창에 실습자료가 안 보이면 그 창의 공유 문서함을 눌러 봅니다. 그래도 없으면 실습 자료 폴더에서 그 파일만 내려받아 ＋ → 파일 업로드로 줍니다.
실습 21교시 · 17:37~17:50 · 공유보드 · Gemini · Gmail · Calendar · 요청 3번

실습 메일을 받아 Gemini로 다루기

보드에서 실습 메일을 받고, Gemini로 메일을 찾아 정리하고, 일정에 넣고, 답장 초안을 쓴다.

순서

  1. 공유보드를 연다 → ‘실습 메일 받기’에 메일 주소와 수업 코드를 넣고 메일 받기를 누른다 — 메일 주소는 지금 Gemini에 로그인한 계정의 주소, 수업 코드는 강사가 채팅으로 알려 준다
  2. Gmail에서 제목이 [실습용]으로 시작하는 메일이 왔는지 본다
  3. Gemini 새 채팅에서 ‘메일 찾기’ 요청문을 보낸다(입력창에 @를 직접 입력해 Gmail을 고른다)
  4. ‘캘린더에 일정 등록’ 요청문을 보내고 Calendar에서 일정 두 개를 확인한다
  5. ‘답장 초안’ 요청문을 보낸다 — 발표 주소 자리는 비워 둔다

요청문

메일 찾기
@Gmail ‘[실습용] 피지컬AI로봇 실습2 · 프로젝트 결과 발표 안내’ 메일을 찾아서 일시 · 장소 · 회신 마감을 표로 정리해 줘.
캘린더에 일정 등록 (메모 포함)
그 메일의 발표 일시와 회신 마감을 내 Google Calendar에 일정으로 추가해 줘.
일정 메모에는 장소와 준비할 것을 적어 줘.
답장 초안
그 메일에 보낼 답장 초안을 써 줘. 팀명은 피지컬AI 2조, 발표 제목은 ‘던지면 받아 주는 쓰레기통 CatchBin’.
발표 주소는 [발표 주소]로 비워 둬.

확인

  • 일시 · 장소 · 회신 마감이 표로 나왔는가
  • 캘린더에 일정 두 개가 생기고 메모에 장소가 들어갔는가
  • 답장은 초안으로만 만들어졌는가
막히면 — ‘수업 코드가 맞지 않습니다’가 나오면 채팅의 코드를 다시 확인합니다(띄어쓰기 · 대소문자). 메일이 안 오면 스팸함과 주소 오타를 확인합니다. 일정이 잘못 만들어졌으면 알림의 ‘실행취소’를 누릅니다. Gmail 연결을 하지 않았으면 강사 화면으로 봅니다.

README와 기록으로 발표 구성안 받기

README와 기록 파일을 주고 표지 + 내용 5장의 발표 구성안을 받아 문서로 저장한다.

순서

  1. Gemini 새 채팅 → ＋ → Drive에서 파일 추가 → 실습자료의 README.md · 기록 폴더의 실험 일지.md · 던지기 기록_60회.csv (안 보이면 내려받아 파일 업로드)
  2. 요청문을 보낸다
  3. 답변 아래 공유 및 내보내기 → Docs로 내보내기 → 문서를 내 폴더로 옮기고 이름을 ‘발표 구성안’으로 — 내보내기가 안 되면 답을 복사해 내 폴더에 새 Google 문서를 만들고 붙여 넣는다
  4. (선택) MD 파일로 받고 싶으면 “이 구성안을 MD 파일로 만들어 줘”

요청문

발표 구성안 받기
첨부한 README와 기록으로 5분 발표의 구성안을 만들어 줘.
- 표지 + 내용 5장: 문제·목표 / 방법·구조 / 구현·실험 / 결과·근거 / 한계·결론
- 장마다 제목은 주장 한 문장, 넣을 숫자와 시각자료를 한 줄씩
- 숫자는 파일에 있는 것만 써 줘

확인

  • 표지 + 내용 5장인가
  • ‘발표 구성안’ 문서가 내 폴더에 있는가
막히면 — 결과가 늦거나 한도 안내가 뜨면 ‘준비본/발표 구성안_예시’를 내 폴더에 넣고 다음으로 갑니다.
실습 42교시 · 18:00~18:14 · Gemini · Drive · Google Slides · 요청 1번

Google Slides도 AI로 — PPTX로 받아 열기

Gemini가 만든 발표를 Google Slides로 연다 — .pptx 파일로 받아 열거나, Canvas에서 바로 연다. PPT는 지금도 쓸모가 많고, 그것도 AI로 만들 수 있다.

순서

  1. Gemini 새 채팅 → ＋ → README.md와 발표 구성안을 첨부 → 요청문 보내기
  2. 결과는 두 가지 모양 중 하나로 나온다 — 같은 요청이어도 그때그때 다르다. 나온 모양대로 아래 둘 중 하나를 한다
  3. 대화에 .pptx 파일이 나오면: 내려받는다 → Drive의 내 폴더에 올리고 더블클릭 → Google Slides로 열린다 → 파일 → Google Slides로 저장
  4. Canvas 슬라이드로 열리면: 내려받지 않고 ‘프레젠테이션으로 열기’를 누른다 → 바로 Google Slides로 열린다
  5. 생긴 Slides 파일을 내 폴더로 옮겨 둔다
  6. 손으로 고쳐 본다: 장표 순서를 끌어 바꾸기, 제목 고치기, 삽입 → 선 → 연결선
  7. (시연) Apps Script로 만들기 — Gemini에게 코드를 받아 script.google.com → 새 프로젝트 → 붙여 넣기 → 실행 → 처음 한 번 권한 허용

요청문

PPTX로 받기
첨부한 README와 구성안으로 발표자료를 PowerPoint(.pptx) 파일로 만들어 줘.
표지 + 내용 5장, 깔끔한 파란색 계열로.
(시연) Apps Script 코드 받기
첨부한 구성안으로 Google Slides를 만드는 Apps Script 코드를 써 줘.

확인

  • 표지 + 내용 5장이 Slides로 열리는가
  • 손으로 한 군데를 고쳐 봤는가
막히면 — .pptx 파일도 Canvas 슬라이드도 안 나오면 ‘준비본/발표_슬라이드 초안.pptx’를 Drive에 올려 엽니다. Apps Script는 수업에서 강사 시연으로만 봅니다 — 무료 계정의 Gemini가 쓴 코드는 오류가 나기 쉽습니다. 수업 뒤에 해 보고 싶으면 ‘준비본/슬라이드 만들기_AppsScript’의 코드를 붙여 넣어 실행합니다(실행할 함수: createDraftSlides).

발표에 두루 쓸 에셋 세트 만들기 — 도식 · 아이콘 · 차트를 SVG로

구조도 · 흐름도 · 아이콘 · 숫자 카드 · 차트를 같은 색과 그림체의 한 세트로 만들어, 한두 군데를 말로 다듬은 뒤 ‘에셋 시트.html’ 파일 하나로 내 폴더에 둔다. 이 세트를 실습 6에서 장표마다 골라 쓰고, 다음 발표와 보고서에도 다시 쓴다.

순서

  1. (먼저 보기) Pinterest에서 ‘diagram asset’, ‘flowchart asset’으로 검색해 마음에 드는 에셋 그림을 캡처해 둔다 — 없으면 레퍼런스 폴더의 레퍼런스2_구조도.png를 쓴다
  2. Gemini 새 채팅 → ＋ → Canvas 켜기
  3. ＋ → Drive에서 파일 추가 → README.md · 실험 일지.md · 레퍼런스2_구조도.png(또는 캡처한 그림)
  4. ‘에셋 세트 만들기’ 요청문을 보낸다 → 미리보기에서 세트(도식 · 아이콘 · 숫자 카드 · 차트)를 확인하고, 오른쪽 위의 코드를 한 번 눌러 본다(그림이 전부 글자다). 답이 중간에 끊기면 “이어서 그려 줘”
  5. 마음에 걸리는 곳을 한두 군데만 말로 다듬는다 — 세트 전체의 선 · 색을 한꺼번에 바꿀 수도 있다. 예시를 따라 하지 않아도 된다
  6. ‘에셋 시트 파일로 받기’ 요청문 → 내려받아 Drive의 내 폴더 → ‘에셋’ 폴더에 올린다 — Gemini가 Drive에 바로 저장하는 기능은 될 때도 안 될 때도 있어, 직접 올리는 것을 기본으로 한다

요청문

에셋 세트 만들기
첨부한 README와 실험 일지로, 이 발표에 두루 쓸 SVG 에셋 세트를 한 장에 모아 만들어 줘.
- 도식: 구조도(인지 → 판단 → 동작), 흐름도(실험 4단계)
- 아이콘 8개: 카메라 · 예측 · 쓰레기통 · 바퀴 · 목표 · 기록 · 결과 · 시간
- 숫자 카드와 차트: 성공률 75%, 예측 오차 6cm, 1차 50% → 2차 75% 막대
